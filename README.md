# 서울 개선루프 (Seoul Fix Loop)

> 막힌 순간을 모아 서울을 고치는 개선루프

2026 서울관광 프롬프톤 **Track 1. 내 손안의 AI 컨시어지** 출품 기획 저장소입니다. 팀: 개선루프.

**이 저장소에는 신청 전 조사 기록만 있습니다.** 대회 규정에 따라 서비스 코드와 프롬프트는 본선 현장(2026-12-11~12)에서 새로 작성합니다.

## 문제: 대부분의 막힘은 기록되지 않는다

외국인 관광객이 서울에서 막힌 실제 사례 142건을 모아 분석했습니다. 2023~2026년 언론 보도 71건과 여행자 커뮤니티 글 71건이며, 단기 관광객 사례는 123건입니다.

- **약 3건 중 1건은 포기하거나, 원치 않는 비용을 그냥 냈습니다.**
- **공식 창구(1330·관광경찰·관광안내소·120)에 도움을 청했다고 확인되는 사례는 3% 안팎이었습니다.**
- 커뮤니티 사례의 약 40%는 외국인 조건에서 막혔습니다. 해외카드, 한국 번호·본인인증, 1인 이용, 외국어 응대가 그 조건입니다.

신고로 이어지지 않은 막힘은 어떤 통계에도 남지 않습니다. 그래서 같은 막힘이 다음 관광객에게도 반복됩니다.

## 해법은 많다. 부족한 것은 순환이다

정보 안내, 번역, 예약 대행 서비스는 이미 많습니다. 공공에는 KTO AI 여행비서·1330, 서울시 택시 QR 신고, 재단 관광불편처리센터가 있습니다. 민간에는 네이버 여권 인증, 캐치테이블 글로벌, 크리에이트립, K.ride가 있습니다.

새로 뜨는 여행 행동(피부과, 세신, 팝업, 퍼스널컬러 등)도 살펴봤습니다. 외국인 질문 72건 중 외국인용 경로가 아예 없는 경우는 행동별 0~12%였습니다.

**부족한 것은 해법의 개수가 아니라, 막힘 → 개선 → 효과 확인으로 이어지는 순환입니다.** 개인 AI 비서는 한 사람만 돕고 끝납니다. 여러 관광객의 막힘을 모아 기관의 개선으로 연결할 수 있는 주체는 재단뿐입니다.

## 서울 개선루프의 구조

```
  ┌──────────── 관광객 ────────────┐
  │  ① 수집: 현장 컨시어지          │  막힌 순간을 돕고(기존 경로로 연결), 기록과 결과를 남김
  └──────────────┬─────────────────┘
                 ▼
  ② 귀납: 자동 분류      두 LLM이 같은 기준으로 독립 분류하고 일치도(kappa)를 측정 → 비슷한 막힘을 묶음
                 ▼
  ③ 가추: 원인 가설      급증·고포기 묶음에 원인 후보와 "참이면 보여야 할 것"을 제시
                 ▼
  ④ 연역: 개선과 예측    맡을 곳별 개선안(재단 / 협력처 / 정책)과 측정 가능한 예측을 생성
                 ▼
  ⑤ 검증: 효과 확인      실행 전후 수치를 코드로 비교 → 틀리면 가설·기준을 수정
                 │
                 └──────────► 다시 ①로 (매주 한 바퀴)
```

### 설계 원칙
- **새 해법을 만들지 않는다.** 이미 있는 공식·민간 경로로 연결하고, 경로가 없거나 작동하지 않는 곳을 찾아낸다.
- **LLM 판단을 그대로 믿지 않는다.** 판정마다 원문 근거를 요구하고, 두 모델의 일치도가 낮으면 사람이 검토한다.
- **성공 여부는 코드가 판정한다.** 개선안의 예측과 실제 수치를 비교하는 일은 LLM에 맡기지 않는다.
- **개인정보를 모으지 않는다.** 가입 없이 쓰고, 사진의 카드번호·얼굴은 가린다. 외부 발송은 담당자 승인 뒤에만 한다.

## 이 방법은 이미 사람 손으로 검증했다

이 기획 자체를 같은 방법으로 만들었습니다. 사례를 수집하고, 분류 기준을 세우고, 두 코더가 독립 분류해 일치도를 쟀습니다. 가설은 데이터를 보기 전에 등록하고 반증 시험을 거쳤습니다. 이 과정을 6차례 반복했고, 그사이 후보 아이디어 다섯 개가 기존 서비스와 겹쳐 탈락했습니다. 자세한 기록은 [docs/research.md](docs/research.md)에 있습니다.

## 데이터 출처
- 사례는 공개된 언론 보도와 여행자 커뮤니티 글에서 모았습니다. 이 저장소에는 집계 결과만 싣고 원문은 재배포하지 않습니다.
- 서울시 관광안내소 표준데이터(서울 열린데이터광장 OA-20350, 공공누리 1유형, 제공 서울관광재단)를 사용했습니다.
